# Claude Dashboard for CEOs and Heads of Departments — 1-Day Workshop

by **Kingsley Low** ([@kingsleylow.ai](https://instagram.com/kingsleylow.ai) on Instagram) — Claude Malaysia

7 lessons, 60 minutes. Every participant leaves with a working dashboard built from their own live data.

> **Paid workshop participants only.** The run link is handed out live in the room and rotates.
> This material may not be reshared, redistributed, or resold. © Claude Malaysia.

## How to run it

Your facilitator gives you the run link on the day. Paste it into **Claude Code** exactly as given.

If you don't have today's link, ask in the workshop WhatsApp group — links from a previous session will not work.

## What you build

| Lesson | What you walk away with |
|---|---|
| 1 | **AI Brain** — Claude knows your role, team and priorities |
| 2 | **A custom skill** — one command that does your weekly job forever |
| 3 | **Connection plan** — every tool sorted, with prompts ready to paste |
| 4 | **Multi-agent workflow** — parallel agents, plus a second skill |
| 5 | **Your dashboard** — real numbers from your connected tools 🏆 |
| 6 | **8am morning brief** — runs before you start your day |
| 7 | The full system |

Everything lands in one visible folder on your Desktop: `my-ai`.

## Before the workshop

Connect your tools in Claude Code: **Settings → Connectors** (Gmail, Calendar, Drive). Lesson 5 pulls your real data from these.

## Install as a plugin (real slash commands)

In Claude Code, add the marketplace:

```
/plugin marketplace add kingsleylow123/1dayclaudedashboardforCEOsandHODs
```

Then install the plugin:

```
/plugin install cm@claude-malaysia-workshop
```

Now run the workshop with slash commands:

| Command | Lesson |
|---|---|
| `/cm:start` | Welcome + Lesson 1 |
| `/cm:lesson1` | Your AI Brain |
| `/cm:lesson2` | Build Your First Skill |
| `/cm:lesson3` | Connect Your Tools |
| `/cm:lesson4` | Parallel AI Agents |
| `/cm:lesson5` | Your 8AM Morning Brief |
| `/cm:lesson6` | Build Your Dashboard 🏆 |
| `/cm:lesson7` | The Finale |

> ⚠️ In the "Add marketplace" box, use the GitHub shorthand `kingsleylow123/1dayclaudedashboardforCEOsandHODs` — a `raw.githubusercontent.com` link will be rejected.
